
# Generative AI Research

This repository contains research materials for the project "Using Generative AI Tools - Boon or Bane."

## Project Structure

- `Literature_Review/` - Contains journal articles, conference papers, books, newspaper articles, and other literature review materials.
- `Quantitative_Analysis/` - Contains survey data, survey questions, Python scripts, CSV files, Excel files, and survey analysis reports.
- `Qualitative_Analysis/` - Contains interview transcripts, interview protocols, consent forms, analysis reports, and data visualisations.
- `Drafts_and_Reports/` - Contains draft research proposals, conference papers, and final reports.
- `Additional_Materials/` - Contains information sheets, photos, and other media files.

## File Navigation

Files are organised into folders according to their type and purpose. Users should open the relevant folder to find the required research materials.

## Collaboration Guidelines

Collaborators should use clear file names and meaningful commit messages. Changes should be committed to the appropriate branch and reviewed before being merged into the main branch.
